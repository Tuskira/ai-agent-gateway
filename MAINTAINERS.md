# Maintainers

This project is maintained by [Tuskira](https://github.com/Tuskira). The
Tuskira team reviews and merges pull requests, triages issues, and cuts
releases.

Contributions from outside Tuskira are welcome. See
[CONTRIBUTING.md](CONTRIBUTING.md) for how to propose a change and
[SUPPORT.md](SUPPORT.md) for where to ask questions.

## Helping maintain the project

Contributors who review pull requests and triage issues regularly may be
invited by the Tuskira team to help with review and triage. Open an issue
if you are interested.

## Review and merge policy

- Every pull request needs at least one maintainer approval before
  merging, except trivial typo/docs fixes a maintainer merges directly.
- Maintainers squash-merge by default (see
  [CONTRIBUTING.md](CONTRIBUTING.md)), which keeps a single clean commit
  per change on `main`.
- A maintainer should not merge their own pull request without another
  maintainer's review, except for urgent fixes (e.g. a broken release
  pipeline) — note the reason in the PR when that happens.
- `CONTRIBUTING.md` covers the technical bar (tests, docs, one topic per
  PR); this file covers who signs off and how.
