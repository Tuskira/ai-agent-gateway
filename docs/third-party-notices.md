# Third-party notices

tusk-ai-secured-gateway is Apache-2.0 (see
[LICENSE](https://github.com/Tuskira/ai-agent-gateway/blob/main/LICENSE)
and
[NOTICE](https://github.com/Tuskira/ai-agent-gateway/blob/main/NOTICE)).
It also bundles a number of third-party, permissively-licensed components.
This page says where to find every one of their license notices; it is not
itself a substitute for them.

## Where the notices live

| What | Where | Generated by |
| --- | --- | --- |
| Go dependencies + standard library | `THIRD_PARTY_NOTICES` in every release archive, and at `/licenses/THIRD_PARTY_NOTICES` inside the container image | `make notices` ([tools/notices](https://github.com/Tuskira/ai-agent-gateway/tree/main/tools/notices)) |
| The embedded React admin console's JS/CSS dependencies | `/licenses.txt` on the running gateway (console port), and inside the Go binary itself | `rollup-plugin-license`, wired into `web/vite.config.ts` |
| The gateway's own license + copyright notice | `LICENSE` and `NOTICE` in every release archive and at `/licenses/` in the image | checked into the repo |
| A software bill of materials (SBOM) for each release archive | attached to every [GitHub Release](https://github.com/Tuskira/ai-agent-gateway/releases) | `syft`, via goreleaser's `sboms` pipe (`.goreleaser.yaml`) |

`THIRD_PARTY_NOTICES` and the console's `licenses.txt` are both generated at
build/release time, not committed to the repository -- see each one's own
`.gitignore` entry and the comments atop `tools/notices/main.go` and
`web/vite.config.ts`.

Every Go module in the gateway's dependency closure (the standard library
plus everything `go list -deps ./cmd/gateway` reaches) is MIT, BSD-2-Clause,
BSD-3-Clause, Apache-2.0, or ISC -- `make notices` fails the build if a
future dependency resolves to anything outside that list (see
`tools/notices/main.go`'s `allowedLicenses`).

The container image's distroless base
([`gcr.io/distroless/static-debian12`](https://github.com/GoogleContainerTools/distroless))
also contains a small number of Debian packages (CA certificates and the
files a static Go binary needs to run as a non-root user). Debian does not
ship one combined NOTICE file for these; see
[the Debian package listing](https://www.debian.org/distrib/packages) and
[snapshot.debian.org](https://snapshot.debian.org) for each package's own
source and license. `THIRD_PARTY_NOTICES`' header carries this same note.

## This docs site's own third-party components

This site (built with [Docusaurus](https://docusaurus.io/), itself
MIT-licensed) pulls in a few third-party pieces worth calling out by name:

- **[@easyops-cn/docusaurus-search-local](https://github.com/easyops-cn/docusaurus-search-local)**
  (MIT) powers the search box, and in turn bundles
  **[lunr-languages](https://github.com/MihaiValentin/lunr-languages)**
  (MPL-1.1), used unmodified, straight from npm (`lunr-languages@1.22.0`).
  MPL-1.1 is file-level copyleft: it only obligates redistributing
  *modified* files of the covered work under MPL, which doesn't apply here
  since the file is unmodified; see its own
  [LICENSE](https://github.com/MihaiValentin/lunr-languages/blob/master/LICENSE)
  for the complete terms.
- **[Scalar](https://github.com/scalar/scalar)** (`@scalar/api-reference`,
  MIT) renders the gateway's own `/api/v1/docs` page (a *different* page
  from this site -- the gateway's embedded API reference, served by the
  running binary). It's loaded directly from jsDelivr at a pinned version
  with a Subresource Integrity hash, not bundled into this site or the
  gateway binary -- see `internal/api/handlers/docs.go`'s `scalarVersion` /
  `scalarIntegrity` and its `cspDocs` Content-Security-Policy, which is the
  one route on the gateway's console origin allowed to load a script from a
  third-party host.
- A handful of this site's own build-time-only npm dependencies --
  **eval**, **format**, and **require-like** (transitive, via
  `@docusaurus/core`) -- predate the convention of a `license` field in
  `package.json` and so don't show up in automated license scans. Checked
  by hand against each package's own `LICENSE`/README: all three are MIT.
  None of them ship in this site's built output; they only run while
  `docusaurus build` runs.
