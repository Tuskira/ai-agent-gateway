# Support

## Documentation

Start with the docs site at [community.tuskira.ai](https://community.tuskira.ai),
built from this repo's [docs/](docs/) folder. It covers configuration,
deployment, the security model, and the architecture of each plane
(API, MCP, LLM).

## Asking a question

Open a new issue and label it `question`. There isn't a separate
discussion forum yet.

## Reporting a bug

Open a new issue and pick the **Bug report** template. Include your
version/commit, deployment method, and reproduction steps — the
template walks you through what's useful.

## Reporting a security vulnerability

Do not open a public issue. See [SECURITY.md](SECURITY.md) for how to
report a vulnerability privately.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for dev setup, coding conventions,
and how to submit a pull request.
